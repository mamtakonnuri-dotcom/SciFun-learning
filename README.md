# Fun Science Learning
Interactive Science website for 1st–3rd Standard students.

All five topics now have an interactive visual explorer:
1. Plants — click each plant part and highlight it separately.
2. Animals & Their Homes — click each animal to focus on it and learn its home.
3. Five Sense Organs — click each sense organ and learn its function.
4. Water Around Us — click each water-use picture and learn about it.
5. Day & Night — click day/night activities and learn when they happen.

Every selected item shows a simple Kannada explanation, with English labels.
There are also topic games and a Science Quiz.

Open `index.html` in Chrome. To publish free, upload these files to a GitHub repository and enable GitHub Pages.
